## Покажи пример. Получи обычное выделение Fusion.

Выберите ребро или грань, откройте контекстное меню и поручите Selectra собрать выделение. Проверьте Magenta-подсветку, измените диапазон и подтвердите результат. Он станет обычным выделением Fusion, готовым для следующей операции моделирования.

**Selectra 1.0.0 включает две команды: Select Similar и Select Chain.** [Возможности выпуска →](docs/releases/1.0.0.ru.md)

| Команда | Что можно сделать |
| --- | --- |
| **Select Similar** | Найти рёбра, грани и группы граней, соответствующие примерам |
| **Select Chain** | Собрать замкнутую петлю рёбер или замкнутый обход стенок |

## Select Similar

Начните с одного ребра или грани. Добавьте **Examples**, чтобы показать, что должно входить в выделение, или укажите лишнее через **Exclude**.

- Форма и размер имеют приоритет перед положением.
- Совпадения в плоскостях примеров идут раньше параллельных и остальных плоскостей.
- Отдельные плоские примеры могут задавать разные семейства формы и размера.
- Связанные грани могут задавать повторяющуюся группу, включая криволинейные стороны пазов.

Область задаётся в **Search Scope**:

| Область | Где искать |
| --- | --- |
| **This Body** | В исходном теле выбранного экземпляра |
| **This Component** | В выбранном экземпляре компонента и его вложенной иерархии; по умолчанию |
| **All Components** | Во всей видимой сборке |

## Select Chain

Выберите ребро, чтобы собрать замкнутую петлю, или грань стенки, чтобы найти замкнутый обход стенок.

**Chain across contact** продолжает контур через полное точное касание тел, например между частями после **Split Body**. Галочка включена по умолчанию. Зазор, частичный контакт и объёмное пересечение не создают перехода. Исходные тела остаются отдельными.

## Два типовых сценария

| Задача | С чего начать |
| --- | --- |
| Найти похожие рёбра или грани | Выбрать примеры → **Select Similar** → уточнить подсвеченный набор |
| Собрать замкнутый контур | Выбрать ребро или грань стенки → **Select Chain** → выбрать контур |

**PgUp / =** добавляет следующий уровень. **PgDown / -** снимает последний включённый уровень. Ползунок управляет тем же диапазоном. Select Similar расширяет набор по похожести, Select Chain переключает целые контуры через все примеры. Колесо мыши остаётся навигации Fusion.

**OK** применяет подсвеченный набор. **Cancel** восстанавливает исходный выбор. Геометрия и таймлайн модели сохраняются.

## Работа в Fusion

Select Similar находит четыре одинаковые полные цилиндрические стенки. Select Chain собирает контур паза через точный стык двух тел. Синий — исходный пример, Magenta — предлагаемый результат.

## Установка

1. Скачайте архив дополнения со [страницы релизов](https://github.com/4FusionLab/Selectra/releases) и распакуйте его в постоянную папку.
2. В Fusion откройте **Utilities → Scripts and Add-Ins**.
3. Нажмите **+ → Script or add-in from device** и выберите папку `Selectra` с файлами `Selectra.py` и `Selectra.manifest`.
4. Выберите **Selectra → Run**. Выделите ребро или грань и откройте контекстное меню.

Fusion использует файлы из этой папки, поэтому сохраняйте её на месте. Selectra работает внутри Autodesk Fusion для Windows и macOS; отдельный Python и дополнительные пакеты не требуются.

[Установка, обновление и удаление →](docs/INSTALLATION.ru.md)

## Ограничения

Selectra работает с BRep-рёбрами и гранями. Эскизные сущности, mesh и T-Spline не входят в область этих команд. Импортированная геометрия подходит, если представлена BRep-телами.

Сходство зависит от доступной геометрии. Одинаковый радиус сам по себе не означает одинаковую деталь: внутренний цилиндр и наружный вал могут иметь один радиус. Проверяйте подсветку перед подтверждением и уточняйте результат через Examples или Exclude.
