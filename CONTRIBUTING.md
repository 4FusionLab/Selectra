# Участие в Selectra

Полезнее всего сейчас — воспроизводимые сценарии выделения и проверка прототипа в Fusion. Перед работой посмотрите [состояние проекта](README.md) и [план](PLAN.md).

## Сообщить о проблеме

Откройте [issue](https://github.com/4FusionLab/Selectra/issues/new/choose). Укажите ОС, полную версию Fusion, версию/commit Selectra, выбранные примеры, ожидаемый и фактический результат. Покажите, какие элементы должны были попасть в набор и какие лишние. Приложите минимальную модель, которую разрешено публиковать, или шаги её построения.

Скриншот помогает проверить подсветку, но не заменяет геометрию и шаги воспроизведения. Удалите личные данные из логов. Для уязвимостей используйте [закрытый канал](SECURITY.md).

## Изменить код

1. Создайте fork и отдельную ветку.
2. Прочитайте [AGENTS.md](AGENTS.md). Сохраните правило поиска внутри тела примера и разделение ядра и Fusion API.
3. Для изменения алгоритма проверьте положительный случай и ложнопохожий элемент, который должен быть исключён.
4. Выполните локальные проверки:

   ```sh
   python -m unittest discover -s tests -v
   python -m compileall -q Selectra scripts tests
   python scripts/check_project.py
   python scripts/build.py
   ```

5. Для UI, adapter и жизненного цикла выполните соответствующие сценарии [CAD-приёмки](docs/VALIDATION.md). Невыполненные проверки обозначьте явно.
6. Обновите документы и Unreleased в [CHANGELOG.md](CHANGELOG.md), затем откройте PR.

Используйте Conventional Commits: `feat:`, `fix:`, `docs:`, `test:`, `ci:`, `chore:`. В PR объясните поведение и приведите результаты проверок. CAD-проверки выполняются в отдельном несохранённом документе.

## Договорённости

- Документация и обсуждения — на русском; сообщения на английском тоже принимаются. Интерфейс Fusion — на английском.
- Ядро получает числовые снимки и не импортирует `adsk`. Runtime-зависимости — стандартная библиотека Python и API Fusion.
- Оценка гипотезы — эвристика, не вероятность намерения пользователя.
- Зелёный CI не считается CAD-приёмкой или проверкой Windows/macOS Fusion.
- Вклад предоставляется под `GPL-3.0-only`. Сохраняйте авторство и совместимые уведомления при использовании стороннего кода.
