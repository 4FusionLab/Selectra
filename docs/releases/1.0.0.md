# Selectra 1.0.0

**English** · [Русский](https://github.com/4FusionLab/Selectra/blob/v1.0.0/docs/releases/1.0.0.ru.md)

**Show an example. Select what matters.** Selectra adds two commands to Autodesk Fusion for selecting edges, faces, and closed contours.

## Select Similar

Find matching geometry from one or more examples. Shape and size take priority; matches in the example planes come before parallel planes, then other planes.

- **Examples** and **Exclude** refine the result.
- **Search Scope** switches between the source body, its component with the nested hierarchy, and the entire visible assembly.
- Connected examples can describe repeating face groups, including curved groove walls.

## Select Chain

Follow a closed edge loop or a wall chain from a selected face.

- Switch between complete contours passing through every example; each choice replaces the previous contour.
- Find boundaries of individual faces, smooth face groups, and connected parts of those groups.
- **Chain across contact**, enabled by default, continues the chain through complete, exact body contact, such as parts created by Split Body.
- The original bodies remain separate. Gaps, partial contact, and overlapping volumes do not create a connection.

## Controls

In Select Similar, **PgUp / =** expands the set and **PgDown / -** narrows it. In Select Chain, these keys choose the next or previous complete contour. The slider controls the same choice.

The magenta highlight shows the proposal before confirmation. **OK** applies ordinary Fusion selection; **Cancel** restores the original selection. Model geometry and the timeline stay unchanged.

## Install

Download the add-in archive from **Assets**, extract it, and add the `Selectra` folder through **Utilities → Scripts and Add-Ins**. No separate Python interpreter or additional packages are required.
