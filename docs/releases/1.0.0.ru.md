# Selectra 1.0.0

[English](https://github.com/4FusionLab/Selectra/blob/v1.0.0/docs/releases/1.0.0.md) · **Русский**

**Покажи пример — выдели нужное.** Selectra добавляет в Autodesk Fusion две команды для работы с рёбрами, гранями и замкнутыми контурами.

## Select Similar

Выделяйте похожую геометрию по одному или нескольким примерам. Форма и размер имеют приоритет; совпадения в плоскостях примеров идут раньше параллельных и остальных плоскостей.

- Примеры **Examples** и исключения **Exclude** уточняют результат.
- **Search Scope** переключает поиск между исходным телом, компонентом с вложенной иерархией и всей видимой сборкой.
- Связанные примеры позволяют искать повторяющиеся группы граней, включая криволинейные стороны пазов.

## Select Chain

Собирайте замкнутую петлю по ребру или обход стенок по выбранной грани.

- Переключение целых контуров через все примеры: каждый вариант заменяет предыдущий.
- Границы отдельных граней, плавных групп и связных частей этих групп.
- **Chain across contact**, включённая по умолчанию, продолжает цепочку через полное точное касание тел, например после Split Body.
- Исходные тела сохраняются отдельными; зазоры, частичный контакт и объёмное пересечение не используются для перехода.

## Управление

В Select Similar **PgUp / =** расширяют набор, **PgDown / -** сужают. В Select Chain эти клавиши выбирают следующий или предыдущий целый контур. Ползунок управляет тем же выбором.

Magenta-подсветка показывает результат до подтверждения. **OK** переносит его в штатное выделение Fusion, **Cancel** восстанавливает исходный выбор. Геометрия и таймлайн модели сохраняются.

## Установка

Скачайте архив дополнения из **Assets**, распакуйте его и подключите папку `Selectra` через **Utilities → Scripts and Add-Ins**. Отдельный Python и дополнительные пакеты не требуются.
