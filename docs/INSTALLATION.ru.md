# Установка Selectra

[English](INSTALLATION.md) · **Русский**

Selectra работает как дополнение Autodesk Fusion для Windows и macOS. Для запуска нужен установленный Fusion; отдельный Python и дополнительные пакеты устанавливать не требуется.

## Скачать

1. Откройте [страницу релизов Selectra](https://github.com/4FusionLab/Selectra/releases).
2. Скачайте архив дополнения из раздела **Assets** выбранного выпуска.
3. Распакуйте архив в постоянную папку на диске.
4. Найдите папку `Selectra`, в которой рядом лежат `Selectra.py` и `Selectra.manifest`.

Fusion использует файлы непосредственно из этой папки. Сохраните её на месте после подключения дополнения.

## Подключить к Fusion

1. Откройте **Utilities → Scripts and Add-Ins**.
2. Нажмите **+ → Script or add-in from device**.
3. Выберите папку `Selectra` с файлами `Selectra.py` и `Selectra.manifest`.
4. Выберите Selectra в списке дополнений и нажмите **Run**.
5. Чтобы дополнение запускалось вместе с Fusion, включите **Run on Startup**.

Названия элементов приведены для английского интерфейса Fusion.

## Начать работу

Откройте Design-документ и выберите BRep-ребро или грань. В контекстном меню доступны:

- **Select Similar** — выделение похожих элементов.
- **Select Chain** — замкнутые петли рёбер и обходы стенок.

Результат показывается Magenta-подсветкой. Нажмите **OK**, чтобы получить обычное выделение Fusion, или **Cancel**, чтобы вернуть исходный выбор.

[Подробное руководство →](GUIDE.ru.md)

## Обновить

1. Завершите открытую команду Selectra.
2. В **Scripts and Add-Ins** выберите Selectra и нажмите **Stop**.
3. Распакуйте новый выпуск и замените файлы дополнения в его постоянной папке.
4. Вернитесь в Fusion и нажмите **Run**.

Если новая версия находится в другой папке, удалите старую запись дополнения и добавьте новую папку через **+ → Script or add-in from device**.

## Удалить

1. Завершите открытую команду Selectra.
2. Остановите дополнение кнопкой **Stop** и отключите **Run on Startup**, если он включён.
3. Уберите запись Selectra из **Scripts and Add-Ins**.
4. Удалите папку дополнения, если она больше не нужна.

## Если команды не появились

Проверьте, что Selectra запущена, открыт Design-документ и выбраны BRep-рёбра либо грани одного типа. Завершите другую активную команду Fusion и снова откройте контекстное меню.

Если дополнение не запускается, убедитесь, что выбрана внутренняя папка `Selectra`, а не корень распакованного репозитория. В ней должны находиться оба файла: `Selectra.py` и `Selectra.manifest`.
