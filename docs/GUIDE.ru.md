# Руководство Selectra

[English](GUIDE.md) · **Русский**

Selectra собирает выделение по примерам и замкнутым контурам. Команды доступны в контекстном меню Fusion при выбранных BRep-рёбрах или гранях.

| Задача | Команда |
| --- | --- |
| Найти похожие рёбра, грани или группы граней | **Select Similar** |
| Выбрать замкнутую петлю рёбер | **Select Chain** |
| Выбрать внутренние стенки по кругу | **Select Chain** |

## Общий порядок работы

1. Выберите исходный пример в модели.
2. Откройте контекстное меню и запустите нужную команду.
3. Проверьте Magenta-подсветку.
4. Уточните примеры или измените диапазон.
5. Нажмите **OK**, чтобы подтвердить результат, либо **Cancel**, чтобы вернуть исходный выбор.

После OK результат становится обычным выделением Fusion. Можно продолжить работу штатными инструментами моделирования.

## Select Similar

### Выбрать примеры

Начните с ребра или грани, похожие на которые нужно найти. В одном наборе используйте сущности одного типа: рёбра либо грани.

Selectra предлагает наиболее близкую группу. Для разных задач учитываются форма, размеры, тип геометрии и расположение относительно примеров.

**Несколько отдельных плоских граней** могут задавать несколько семейств формы и размера. Например, небольшая и крупная фигурные грани позволяют собрать аналоги обоих размеров.

**Связанные грани** могут задавать образец целой группы. Это удобно для повторяющихся узлов и внутренних сторон пазов: важны форма участников и их взаимное расположение.

**Examples** позволяет добавить или убрать пример прямо в диалоге. Добавление примера пересчитывает результат и возвращает автоматический диапазон.

### Выбрать область

| Search Scope | Область |
| --- | --- |
| **This Body** | Тело исходного примера в выбранном экземпляре |
| **This Component** | Компонент первого примера и вся его вложенная иерархия |
| **All Components** | Все видимые доступные тела сборки |

По умолчанию выбрана **This Component**. Другие экземпляры того же компонента не включаются только потому, что используют одно определение: они должны входить в выбранную иерархию либо в **All Components**.

Примеры и исключения должны находиться в текущей области. Чтобы сузить поиск, сначала удалите примеры, которые окажутся за её пределами.

### Расширить или сузить результат

**Similarity** управляет диапазоном похожести. Расширение добавляет следующую группу, сужение снимает последнюю включённую группу. Примеры сохраняются.

Для одинаковой геометрической группы порядок такой:

1. В плоскостях примеров.
2. В параллельных плоскостях.
3. В остальных плоскостях.

Пустые группы пропускаются. При дальнейшем расширении становятся доступны более общие совпадения — сверяйтесь с подсветкой и пояснением в диалоге.

| Действие | Клавиши |
| --- | --- |
| Расширить диапазон | **PgUp** или **=** |
| Сузить диапазон | **PgDown** или **-** |

Ползунок и клавиши управляют одним диапазоном. Колесо мыши продолжает управлять видом Fusion.

### Убрать лишнее

В **Exclude** укажите элемент, который не должен входить в результат. Selectra пересчитает предложение с учётом этого уточнения.

Для поиска повторяющихся групп исключение участника может отклонить всю соответствующую группу. Это помогает сохранить целостность набора.

### Задать критерий явно

В разделе **Refine → Match** можно выбрать доступный критерий, например **Area**, **Length**, **Radius** или **Orientation**. Набор вариантов зависит от выбранной геометрии.

**Automatic** использует геометрический смысл примеров. Явный критерий полезен, когда нужен конкретный признак: например, одинаковый радиус при разных остальных размерах.

**Reset Range** возвращает автоматический диапазон.

## Select Chain

### Замкнутая петля рёбер

Выберите ребро нужного контура и запустите **Select Chain**. Selectra предложит ближайшую замкнутую петлю, проходящую через пример.

Несколько рёбер могут уточнить, какой контур нужен. Начальный набор должен образовывать один замкнутый обход через все примеры.

### Замкнутый обход стенок

Выберите грань внутренней стенки паза или кармана. **Select Chain** соберёт стенки замкнутого обхода. Внутренние контуры имеют приоритет перед более широкими внешними обходами.

Результат состоит из граней, поэтому после OK можно продолжить работу с поверхностями стенок.

### Переход между телами

**Chain across contact** включена по умолчанию. Она позволяет продолжить цепочку между телами с полным точным касанием, например между частями после **Split Body**.

Переход не строится через зазор, частичное касание или объёмное пересечение. Совпадения только концов рёбер тоже недостаточно. Исходные тела остаются отдельными, их геометрия и таймлайн сохраняются.

Отключите галочку, чтобы ограничить цепочки топологией отдельных тел.

### Диапазон цепочек

**Contour** и клавиши **PgUp / =**, **PgDown / -** переключают целые замкнутые контуры через все примеры. Каждый вариант заменяет предыдущий.

Если через выбранные примеры не найден замкнутый контур, Selectra сообщает об этом. Выберите другой пример или уточните начальный набор.

## Подсветка и подтверждение

**Magenta** показывает предложенный набор до его переноса в выделение. Последняя добавленная группа получает дополнительный контурный акцент.

- **OK** подтверждает набор и закрывает команду.
- **Cancel** возвращает исходный выбор.

Для продолжения поиска после изменения геометрии модели завершите команду и запустите её заново.
