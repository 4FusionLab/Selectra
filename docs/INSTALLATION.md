# Подключение прототипа к Fusion

Версия 0.0.1 предназначена для разработки. Работа меню, подсветки, подтверждения и отмены в Fusion ещё не проверена. Используйте отдельный несохранённый документ по [протоколу](VALIDATION.md).

## Получить файлы

На [странице репозитория](https://github.com/4FusionLab/Selectra) выберите **Code → Download ZIP** и распакуйте архив либо клонируйте репозиторий. ZIP из артефактов GitHub Actions тоже содержит прототип; зелёный CI не подтверждает работу Fusion.

Найдите внутреннюю папку `Selectra`, где рядом лежат `Selectra.py`, `Selectra.manifest`, `matching.py` и `fusion_adapter.py`.

## Добавить через интерфейс

1. В Fusion откройте **Utilities → Scripts and Add-Ins**.
2. Нажмите **+ → Script or add-in from device** и выберите внутреннюю папку `Selectra` с manifest и одноимённым Python-файлом.
3. Выберите Selectra и нажмите **Run**. `Run on Startup` в прототипе выключен.
4. В тестовом Design-документе выберите BRep-рёбра либо грани одного тела корневого компонента. Ожидаемая точка входа — **ПКМ → Select Similar** из штатной команды Select.

Названия приведены для английского интерфейса. macOS и Windows — целевые платформы; работа Selectra требует CAD-проверки.

Fusion связывает дополнение с папкой на диске. Сохраняйте её на месте. Установка через `pip` и отдельный системный Python для запуска дополнения не нужны.

## Обновить или удалить

Нажмите **Stop** и закройте диалог Selectra. Обновите исходники в той же папке, затем нажмите **Run**. При смене пути заново добавьте папку.

Для удаления остановите дополнение, уберите его запись из Scripts and Add-Ins и удалите папку, если она больше не нужна. Назначение Selectra — менять выделение, сохраняя геометрию и таймлайн модели.
