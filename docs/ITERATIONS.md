# Инженерные итерации Selectra

Дата начала: 25.10.2026. Baseline: `c5ac432` (`ranking.py` из `8bcec25`). Работа продолжается в `codex/smart-selection`.

## Порядок работы

1. Зафиксировать baseline и размеченный офлайн-корпус. Параллельно реализовать сравнение контуров и проверку пар стенок. Координатор интегрирует контракты и нативное извлечение данных.
2. Внедрить геометрические группы: аналог формы → пара стенки примера → пары найденных аналогов → остальные семейства. Проверить вложенность, полное ранжирование и атомарные ничьи; уточнения должны выбирать объяснимые гипотезы.
3. Добавить устойчивый контур последней добавленной группы к Magenta-заливке 35%. Проверить ограниченный поиск повторов с геометрией; отдельно оценить логические поверхности STEP без потери ссылок на исходные грани.
4. Выполнить офлайн-сравнение с baseline, независимое ревью и исправления. Затем координатор проводит одну последовательную CAD-сессию в отдельном несохранённом документе. Субагенты Fusion не вызывают.
5. Зафиксировать измерения, ограничения и невыполненную матрицу; проверить упаковку, закоммитить и отправить рабочую ветку. Стабильный релиз требует отдельной полной CAD-приёмки.

## Владение файлами и контракт

- Геометрия: `Selectra/contours.py`, `tests/test_contours.py`. Чистые функции над tuple петель из 3D-точек; первая петля наружная. Проверка конгруэнтности допускает перенос, вращение и отражение, сохраняет размеры. Неизвестная/неполная граница не является доказанным аналогом.
- Отношения: `Selectra/walls.py`, `tests/test_walls.py`. Планарные патчи (ключ, нормаль, положение, петли) и явные свидетельства материала. Проверка осей, локального смещения и пересечения проекций. Нет данных о материале — нет подтверждённой стенки.
- Оценка: `evaluation/`, `scripts/evaluate_selection.py`, `tests/test_evaluation.py`. Baseline заморожен, ожидаемые наборы задаются независимо от нового ранжирования. Камера не входит в числовой снимок.
- Координатор: `matching.py`, `snapshot.py`, `ranking.py`, `selection.py`, `fusion_adapter.py`, `highlight.py`, `Selectra.py`, общая документация. Изменения общих контрактов сообщаются всем до интеграции. Другие файлы субагенты не меняют без согласования.

## Критерии приёмки

- Все сущности исходного типа и тела ранжированы. Примеры сохраняются, исключения отсутствуют; область поиска не расширяется. Перестановка ключей не разбивает равноценные группы.
- Равная площадь/периметр при другой границе не считается конгруэнтностью. Контур устойчив к жёстким преобразованиям и отражению; отверстия проверяются вместе с размещением.
- Пустой зазор между поверхностями не считается стенкой. Отчёт различает подтверждённую связь и ограниченное дискретное свидетельство материала.
- В корпусе измеряются точность первого набора, precision/recall, минимальные шаги до целевого набора и недостижимые цели; уточнения и инвариантности проверяются отдельно. Время чтения, анализа и графики не смешивается.
- Нативно: первый набор, PgUp/PgDown, Examples/Exclude, OK/Cancel, очистка графики, отсутствие изменений геометрии/таймлайна. Проверка API definitions и unit-тесты не заменяют визуальную приёмку.
- Итог каждого этапа заносится в `docs/EVALUATION.md`; незавершённые функции не объявляются готовым продуктом. Windows CAD проверяется отдельно.
