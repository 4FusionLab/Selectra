# Офлайн-замеры ядра

25.10.2026, Python 3.14.5, macOS 27.0.1 ARM64. Три повтора; в таблице медиана. Данные синтетические: числовые дескрипторы прямых рёбер с пятью длинами и двумя направлениями.

| Кандидаты + пример | Отдельные гипотезы, мс | Общее ранжирование, мс | Пара шагов диапазона, мс |
| --- | ---: | ---: | ---: |
| 100 + 1 | 0.352 | 0.379 | 0.018 |
| 1 000 + 1 | 3.295 | 3.609 | 0.021 |
| 10 000 + 1 | 32.475 | 36.609 | 0.029 |

Это не задержки Fusion. В замер не входят чтение BRep, построение CustomGraphics, обработка клавиатуры приложением или перерисовка viewport. Пара шагов измеряет изменение диапазона на уже готовом ранжировании, без нового извлечения признаков.

Повторить:

```sh
python scripts/benchmark_offline.py --repeats 3
```

В живой контрольной сессии `tests/fusion_read_contract.py` проверил 97 рёбер и 39 граней с восемью примерами каждого типа примерно за 0.03 секунды. Это ограниченный read-only контракт на одной модели, не общий CAD-бенчмарк.
