# Публикация Selectra

Selectra использует GitVersion 6.8.2 как источник версии X.Y.Z. Для стабильных релизов тег имеет вид `vX.Y.Z`, для предварительных — `vX.Y.Z-IDENTIFIER`. Версия в опубликованном Fusion manifest и имени ZIP всегда числовая X.Y.Z и должна совпадать с GitVersion. Релизные файлы собирает и публикует только GitHub Actions.

## Каждый push и pull request

CI проверяет Python 3.14 на Ubuntu, macOS и Windows: синтаксис, unit-тесты, документы, manifest и ZIP. Версии сторонних Actions закреплены полными commit SHA; Dependabot предлагает обновления отдельными PR.

Каждая ОС загружает артефакт `Selectra-package-Linux`, `Selectra-package-macOS` или `Selectra-package-Windows` с ZIP и SHA-256. Workflow не запускает Fusion и не заменяет CAD-приёмку.

## Стабильный выпуск

1. Пройти CAD-сценарии на заявляемых платформах и записать Fusion/ОС, выполненные проверки и ограничения в [протокол](VALIDATION.md). Автоматические проверки и нативную приёмку указывать отдельно.
2. Рассчитать версию через GitVersion, обновить README, CHANGELOG и обе страницы `docs/releases/X.Y.Z.md` / `X.Y.Z.ru.md`. Сделать реальные демо-снимки Fusion. CI подставляет GitVersion в manifest **внутри ZIP**, не меняя исходный файл в репозитории.
3. Проверить установку распакованного ZIP через GUI Fusion. Локальная сборка используется только для проверки, не для загрузки в Release.
4. Выполнить локальные проверки и дождаться зелёного CI выпускаемого commit. Перенести проверенный commit в main и создать новый тег `vX.Y.Z` (либо `vX.Y.Z-IDENTIFIER` для prerelease) без переписывания существующих тегов.
5. Push тега запускает полную CI-матрицу повторно. Зависимый job `release` скачивает все три пакета, сверяет manifest и SHA-256 и требует побайтового совпадения архивов.
6. `scripts/publish_release.py` создаёт draft, загружает ZIP и checksum из CI, проверяет серверные digest и публикует `draft=false`: стабильная версия получает `prerelease=false` и Latest, предварительная — `prerelease=true` и не становится Latest. Токен выдаётся GitHub Actions только job публикации. Локальная публикация запрещена скриптом.
7. Прочитать опубликованные метаданные, скачать ZIP и SHA-256 со страницы релиза, проверить состав и контрольную сумму. Ссылка на CI и commit включается в описание автоматически.

Архивы называются `Selectra-X.Y.Z.zip` независимо от канала; канал задаёт Git-тег и GitHub Release. При несовпадении GitVersion, manifest, версий трёх пакетов ОС или checksum публикация блокируется. Повторный запуск не подменяет отличающиеся файлы опубликованного релиза.
