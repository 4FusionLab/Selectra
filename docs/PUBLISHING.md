# Публикация Selectra

Selectra публикуется стабильными версиями X.Y.Z. Статус GitHub Release, manifest и имя ZIP должны совпадать. Релизные файлы собирает и публикует только GitHub Actions.

## Каждый push и pull request

CI проверяет Python 3.14 на Ubuntu, macOS и Windows: синтаксис, unit-тесты, документы, manifest и ZIP. Версии сторонних Actions закреплены полными commit SHA; Dependabot предлагает обновления отдельными PR.

Каждая ОС загружает артефакт `Selectra-package-Linux`, `Selectra-package-macOS` или `Selectra-package-Windows` с ZIP и SHA-256. Workflow не запускает Fusion и не заменяет CAD-приёмку.

## Стабильный выпуск

1. Пройти CAD-сценарии на заявляемых платформах и записать Fusion/ОС, выполненные проверки и ограничения в [протокол](VALIDATION.md). Автоматические проверки и нативную приёмку указывать отдельно.
2. Обновить manifest, README, CHANGELOG и обе страницы `docs/releases/X.Y.Z.md` / `X.Y.Z.ru.md`. Сделать реальные демо-снимки Fusion. Версия берётся из manifest.
3. Проверить установку распакованного ZIP через GUI Fusion. Локальная сборка используется только для проверки, не для загрузки в Release.
4. Выполнить локальные проверки и дождаться зелёного CI выпускаемого commit. Перенести проверенный commit в main и создать тег `vX.Y.Z` без переписывания существующих тегов.
5. Push тега запускает полную CI-матрицу повторно. Зависимый job `release` скачивает все три пакета, сверяет manifest и SHA-256 и требует побайтового совпадения архивов.
6. `scripts/publish_release.py` создаёт draft, загружает ZIP и checksum из CI, проверяет серверные digest и публикует `draft=false`, `prerelease=false`, Latest. Токен выдаётся GitHub Actions только job публикации. Локальная публикация запрещена скриптом.
7. Прочитать опубликованные метаданные, скачать ZIP и SHA-256 со страницы релиза, проверить состав и контрольную сумму. Ссылка на CI и commit включается в описание автоматически.

Стабильные архивы называются `Selectra-X.Y.Z.zip`. При несовпадении версий, пакетов ОС или checksum публикация блокируется. Повторный запуск не подменяет отличающиеся файлы опубликованного релиза.
