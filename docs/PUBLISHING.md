# Публикация Selectra

Репозиторий содержит исходники прототипа. Публикация исходников и выпуск проверенного дополнения — разные этапы.

## Каждый push и pull request

CI проверяет Python 3.14 на Ubuntu, macOS и Windows: синтаксис, unit-тесты, документы, manifest и ZIP. Версии сторонних Actions закреплены полными commit SHA; Dependabot предлагает обновления отдельными PR.

Артефакт `Selectra-prototype` содержит ZIP и SHA-256. Автоматического создания тегов и GitHub Releases нет. Workflow не запускает Fusion и не подтверждает CAD-приёмку.

## Перед релизом

1. Пройти [CAD-матрицу](VALIDATION.md) на заявляемых платформах. Записать Fusion/ОС, commit, выполненные сценарии и ограничения.
2. Обновить `Selectra/Selectra.manifest`, README и CHANGELOG. Версия берётся из manifest.
3. Выполнить проверки из [CONTRIBUTING.md](../CONTRIBUTING.md) и дождаться зелёного CI выпускаемого commit.
4. Проверить установку распакованного ZIP из чистой папки через GUI Fusion.
5. Создать тег `vX.Y.Z` на проверенном commit и вручную создать GitHub Release с ZIP, SHA-256, возможностями и результатами CAD-приёмки. Экспериментальные версии отмечать **pre-release**.
6. Прочитать опубликованные метаданные, скачать артефакт и проверить состав и SHA-256.

При первом стабильном выпуске убрать суффикс `-prototype` из сборщика и синхронно обновить документацию и тесты. Стабильный статус требует CAD-приёмки.
