# Вопросы и ответы

[English](FAQ.md) · **Русский**

## Чем отличаются Select Similar и Select Chain?

**Select Similar** ищет похожую геометрию по примерам. **Select Chain** собирает замкнутый контур: петлю рёбер или обход стенок.

## Какие объекты можно выбирать?

BRep-рёбра и грани, включая геометрию в компонентах и сборках. В одном наборе примеров используются либо рёбра, либо грани.

Эскизные линии, mesh и T-Spline не входят в область этих команд. Импортированная модель подходит, если её геометрия представлена BRep-телами.

## This Component включает вложенные компоненты?

Да. Включается выбранный экземпляр компонента и его вложенная иерархия. Соседний экземпляр того же определения автоматически не добавляется. Для поиска по всей видимой сборке используйте **All Components**.

## Почему часть элементов не попала в первый набор?

Первый набор содержит ближайшую предложенную группу. Расширьте диапазон через **PgUp**, **=** или ползунок.

В Select Similar положение по плоскостям учитывается отдельными шагами: сначала плоскости примеров, затем параллельные, затем остальные. Select Chain переключает целые контуры через все примеры.

## Что делать, если найдено лишнее?

В **Select Similar** добавьте более показательный пример в **Examples** или укажите лишний элемент в **Exclude**. Для конкретной задачи можно выбрать явный критерий в **Refine → Match**.

В **Select Chain** уточните исходные рёбра или грани, через которые должен проходить контур, либо сузьте **Contour**.

## Одинаковый радиус означает одинаковую деталь?

Нет. Радиус — один из признаков геометрии. Например, внутренний цилиндр и наружный вал могут иметь одинаковый радиус. Если выбран явный **Match → Radius**, в набор могут входить разные по назначению элементы.

Проверяйте предложенный результат по подсветке перед OK.

## Можно построить цепочку через несколько тел?

Да, с включённой **Chain across contact**, если тела имеют полное точное касание. Это подходит, в частности, для частей после **Split Body**.

Зазор, частичный контакт, касание только в точке или по ребру и объёмное пересечение не используются как переход. При выключенной галочке цепочки ограничены топологией отдельных тел.

## Selectra объединяет тела или создаёт геометрию?

Нет. Результат работы — выделение исходных рёбер и граней. Геометрия и таймлайн модели сохраняются.

## Почему команды нет в контекстном меню?

Проверьте, что дополнение запущено, открыт Design-документ и выбраны BRep-рёбра либо грани одного типа. Завершите другую активную команду Fusion и откройте меню снова.

[Инструкция по подключению](INSTALLATION.ru.md)

## Нужно устанавливать Python?

Нет. Selectra использует Python, поставляемый с Fusion. Отдельный интерпретатор и установка пакетов не нужны.

## Где выполняется поиск?

Внутри Fusion на вашем компьютере. Selectra не отправляет модель внешним сервисам для поиска похожей геометрии.

## Почему после изменения модели нужно запустить поиск заново?

Результат относится к геометрии, считанной при запуске команды. После изменения тела или положения компонента завершите текущий поиск и запустите его заново.

## Как сообщить об ошибке?

Создайте [issue](https://github.com/4FusionLab/Selectra/issues/new/choose). Укажите версии Selectra и Fusion, операционную систему, команду, примеры, ожидаемый и фактический результат.

Скриншот помогает показать выделение; минимальная модель или шаги её построения помогают воспроизвести проблему. Прикладывайте только материалы, которые разрешено публиковать. Для сообщений об уязвимостях используйте [закрытый канал](../SECURITY.ru.md).
