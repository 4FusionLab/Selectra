# История изменений

## Unreleased

Начальная публичная версия исходников; стабильный релиз не опубликован.

### В разработке после инициализации

- Все сущности выбранного типа исходного тела ранжируются по сходству. PgUp/PgDown и ползунок управляют вложенным диапазоном; одинаковые оценки включаются вместе.
- Примеры и исключения пересчитывают общие признаки; исходные примеры сохраняются, исключения не включаются.
- Automatic сравнивает ось нормали плоской грани с меньшим весом: параллельная внутренняя стенка не уступает поперечной из-за направления наружной нормали. Явный Orientation остаётся направленным.
- Начальный диапазон сразу включает первую непустую группу кандидатов; Magenta-заливка имеет непрозрачность 35%.
- Preview как поле убран: результат показан устойчивой Magenta-графикой, настоящий выбор применяется по OK. Колесо возвращено навигации Fusion.
- Защита scope/revision, история состояния, точный ограниченный поиск топологических регионов, Linked/More/Less и пути в офлайн-ядре.
- Добавлены UX-спецификация, матрица Blender, замеры и read-only контракт на настоящем BRep.
- Пользовательский логотип сохранён оригинальным PNG и включён в README и ZIP без изменения байтов.
- Выполнена частичная нативная приёмка рёбер/граней в Fusion на macOS; подробности в docs/VALIDATION.md.

### Добавлено

- Гипотезы сходства по длине, направлению, площади, радиусу и простой сигнатуре границы.
- Уточнение общих признаков по нескольким примерам и обнаружение неоднозначности.
- Прототип `Select Similar`, нативного предпросмотра и переноса выделения.
- Поиск внутри тела примера; начальная поддержка ограничена корневым компонентом.
- Исследование API, сценарии и протокол CAD-приёмки.
- GPL-3.0-only, правила участия, шаблоны issues/PR, CI и воспроизводимая сборка ZIP с SHA-256.

### Ограничения

- Полная матрица приёмки и Windows Fusion ещё не пройдены.
- Распознавание отверстий/скруглений, component occurrences и работа внутри чужих команд не реализованы.
